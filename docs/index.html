为"坚持不下来"而生的功能

不做花里胡哨的学习社交，只解决一件事：到点了，认真问自己一句——完成了吗？

定时询问

开始任务后按设定间隔（默认每小时）反复确认进度，答「还没完成」就继续追问，直到你真正做完。

里程碑打卡

把大目标拆成小目标逐项勾选，例如「看完 string 命令 → 学完 hash 与 zset」，全部完成才算结束。

灵活重复规则

每天、每周固定一天、每月固定日期，或自定义每周哪几天（一键选工作日）。非执行日安静不打扰。

学习链接直达

给任务挂上教程或文档地址，提醒通知和确认卡片上会出现「立即学习」，点开直接进入学习页面。

系统通知带按钮

通过 Windows 原生通知中心提醒，通知上直接选择「已完成 / 还没完成 / 稍后再说」，不切窗口也能打卡。

日历查看记录

月历用颜色标出每一天的完成度（全部完成 / 部分完成 / 未完成），点选任意一天查看当天的检查流水。

常驻低占用

基于 .NET 8 WPF 原生开发，纯托盘驻留时私有内存约 20MB，不内嵌浏览器内核，可 7×24 小时后台运行。

数据本地存储

任务与记录保存在本机 JSON 文件中，不登录、不上传、不联网收集任何个人信息，文件损坏会自动备份。

开机自启

一键开启登录后自动启动并静默驻留托盘，早上打开电脑，它已经在那里等你开始今天的计划。
