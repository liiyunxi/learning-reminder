快速开始

下载自包含版 exe 后双击运行。应用启动后会出现在系统托盘区（任务栏右下角；如果看不到，点击托盘区的 ^ 展开隐藏图标），同时打开主窗口。

  • 关闭主窗口不会退出应用，它会继续在托盘里常驻提醒；
  • 再次打开主窗口：左键单击或双击托盘图标，也可以右键选择「打开主界面」；
  • 完全退出：右键托盘图标，选择「退出」。

创建任务

在主窗口底部点击「新建任务」，在弹窗中填写：

  • 任务名称：例如「学习 Redis 数据类型」；
  • 学习链接（可选）：教程、视频或文档地址，填了之后提醒时会多一个「立即学习」按钮；
  • 分组标签（可选）：例如「英语」「编程」，设置后主界面可按分组筛选；
  • 重复：每天 / 每周 / 每月 / 自定义，详见下文；
  • 检查方式：定时询问 或 里程碑；
  • 根据检查方式设置询问间隔（分钟）或每日核对时间与里程碑清单。

已有的任务可以随时在任务卡片上点「编辑」修改，点「删除」移除（删除任务不会删掉历史检查记录）。任务卡片上还有「停用 / 启用」开关：停用的任务不再提醒、不计入统计与托盘进度，随时可以一键恢复。

分组与模板

给任务设置分组标签后，「今日任务」页顶部会出现一排筛选按钮：「全部」加上所有使用中的分组。点某个分组只显示该组任务，再点「全部」恢复；标签留空的任务只出现在「全部」视图里。

模板用于快速复用常用配置：新建任务弹窗顶部内置「背单词 / 看视频课 / 读书 / 编程练习」四个模板，点击即自动填好名称、检查方式、间隔或里程碑清单与分组；当前填写的内容也可以点「保存为模板」另存，自建模板右侧的「×」可删除。

两种检查方式

1. 定时询问（按小时制）

适合"今天要持续推进"的学习任务。设定一个询问间隔（默认 60 分钟，可在 5–1440 分钟之间调整，提供 30/60/90/120 快捷选项）：

  • 到点后系统通知弹出「已完成 / 还没完成 / 15 分钟后再问」；
  • 选「还没完成」：按间隔继续追问；
  • 选「已完成」：当天不再提醒，任务卡片标记「今日已完成」；
  • 选「稍后再说」：推迟 15 分钟后再问；
  • 长时间不应答（约 5 分钟）：自动按「稍后再说」处理，避免待办堆积。

当天的完成标记在跨天（午夜后）自动重置，第二天按重复规则重新开始。

2. 里程碑（按完成情况）

适合有明确子目标的任务，例如「学完 Redis 的类型」可以拆成：

  • 看完 string 常用命令
  • 学完 hash 与 zset
  • 理解 list / set 的使用场景

每个里程碑的完成状态跨天保留，不会第二天清零。可以设置「每日核对时间」（默认 21:00）到点提醒勾选；全部里程碑勾完后任务才标记完成。也可以勾选「不主动提醒」，只靠手动检查推进。

重复规则

  • 每天：每个自然日都执行；
  • 每周：固定一个星期几执行，例如每周一做复盘；
  • 每月：每月固定日期执行，例如每月 1 日整理笔记。当月没有该日期时（如 2 月没有 31 号），自动顺延到当月最后一天；
  • 自定义：勾选每周哪几天执行，提供「工作日」快捷按钮一键选择周一至周五。

非执行日：任务不会出现在「今日任务」列表里，也不会触发任何提醒，主界面底部会以一行灰字列出今天不执行的任务。

学习链接

链接支持 http:// 或 https:// 地址，只填域名时会自动补全为 https。任务带有链接时，三个位置会出现学习入口：

  1. 系统通知上的「立即学习」按钮；
  2. 右下角确认卡片上的「立即学习」按钮（点击后卡片保留，方便学完回来打卡）；
  3. 主界面任务卡片上的「打开链接」按钮。

点击后调用系统默认浏览器打开对应网页。

提醒与应答

提醒按优先级有三种表现形式，保证你一定能完成打卡：

  1. Windows 系统通知：带操作按钮，在通知上点选即可，无需切换窗口；
  2. 右下角确认卡片：通知发出约 20 秒未处理时自动出现，不抢焦点、不占任务栏，带 90 秒倒计时；里程碑模式还能直接在卡片上勾选子目标；
  3. 托盘气泡：系统通知不可用时的兜底通道，点击气泡打开确认卡片。

如果系统开启了「请勿打扰 / 专注助手」，通知横幅会被系统拦截，但通知仍会进入通知中心，确认卡片也会照常出现。

免打扰与提醒节奏

在「设置 → 提醒」里可以开启免打扰时段（默认 22:30 至次日 07:30，可自行修改）：

  • 时段内不发起任何系统通知、气泡与确认卡片，到点的排期直接跳过、不会补发；
  • 里程碑任务的「每日核对时间」如果落在免打扰时段内，当天将不会提醒，建议把核对时间设到时段之外；
  • 同一处还可以调整「稍后再说」的推迟时长与新建任务的默认询问间隔。

间隔自适应：连续选择「还没完成」时，询问节奏自动放缓（第一次 ×1.5、之后 ×2，上限 24 小时），避免越问越频繁；标记完成即恢复原始间隔。

通知聚合：短时间内产生的多条待确认会合并为一条汇总通知，点击后打开确认卡片逐项处理。

托盘与开机自启

托盘图标有三种颜色状态：靛蓝＝有待办任务，橙色＝有等待你确认的询问，绿色＝今日任务全部完成。鼠标悬停可看到「今日 x/y 完成」。

开启开机自启有两种方式：

  • 主窗口底部勾选「开机自启」，或右键托盘图标勾选「开机自启」；
  • 原理是写入当前用户的注册表 Run 项（HKCU\Software\Microsoft\Windows\CurrentVersion\Run），不需要管理员权限；登录后应用以 --minimized 静默启动并弹出一次气泡提示。

应用只允许运行一个实例：再次启动时新进程会自动退出并把已有窗口唤到前台。

全局快捷键与状态总览

两个全局快捷键无论应用是否在前台都生效：

  • Ctrl+Alt+L：打开（或唤到前台）主界面；
  • Ctrl+Alt+K：立即检查全部任务，对今天所有未结束的任务立刻发起一次询问。

右键托盘图标时，菜单顶部会显示「今日完成 x/y」，下方逐条列出今天的任务与完成状态（√ 已完成 / ○ 未完成），不用打开主窗口就能掌握进度。任务较多时按今日清单顺序显示前 10 条。

日历与记录

「记录」页左侧是月历，每格用颜色和圆点表示当天完成度：

  • 绿色底：当天应执行的任务全部完成；
  • 橙色底：完成了一部分；
  • 灰色圆点：当天有任务但没有完成；
  • 紫色描边：今天。

点击任意日期，右侧显示当天的检查流水（标记完成 / 仍未完成 / 稍后再说 / 未应答自动推迟 / 里程碑进度）。可以用顶部箭头切换月份，或点「回到今天」快速返回。

学习计时与补打卡

任务卡片上的「开始学习 / 结束学习」按钮用来记录本次学习时长：点击开始后卡片上实时计时，点「结束学习」或把任务标记完成时自动累计到当天；每日与区间的时长合计可以在「统计」页查看。

漏打卡可以事后补记：在「记录」页选中过去的日期，右侧「当天任务」列表中未完成的任务会显示「补打卡」按钮，点击即补记为完成，记录里会标注「补打卡」以便与正常打卡区分。补打卡只对过去的日期开放，当天请走正常打卡流程。

统计与成就

「统计」页签集中展示坚持情况：

  • 连续完成：连续多少天全部完成任务；今天尚未完成不会打断连击，没有任务安排的日子自动跳过；
  • 每日目标：可在设置中设定每日目标任务数（0 表示不设目标），统计页显示当天达成进度；
  • 近 7 天趋势：每天一根柱子，绿色＝当天全部完成、橙色＝部分完成，鼠标悬停查看完成数；
  • 本月汇总：完成数、完成率、全勤天数与学习时长合计；
  • 成就：初次打卡、三日 / 七日 / 半月连击、累计打卡次数、累计学习时长、里程碑与早起打卡等 10 项成就，达成即点亮（灰色为未达成，并显示进度）。

数据与备份

所有数据只保存在本机当前用户目录下：

  • 数据文件：%AppData%\LearningReminder\data.json
  • 错误日志：%AppData%\LearningReminder\log.txt

写入采用「临时文件 + 原子替换」，异常断电不会写坏文件；万一文件损坏，应用会自动把原文件改名为 data.json.broken 备份后重新开始。检查记录在本地保留最近 60 天。备份或迁移时，复制整个 LearningReminder 文件夹即可。

「设置 → 数据与隐私」提供四项数据能力：

  • 自动备份：每天首次启动时自动把数据文件复制到 %AppData%\LearningReminder\backups，最多保留 10 份；也可以随时点「立即备份」（按时间戳单独保存，不会覆盖当天自动备份）；
  • 导出 / 导入：导出为明文 JSON 文件，便于换机迁移或人工查看；导入会先自动备份当前数据、二次确认后整体替换；
  • 本地加密：开启后数据文件使用 Windows DPAPI 加密，只有当前 Windows 账户能解密；加密文件复制到别的账户或电脑无法直接读取，跨设备迁移请先用「导出」；
  • 打开数据目录：一键定位数据、日志与备份所在文件夹。

退出与卸载

  1. 右键托盘图标 →「退出」，结束常驻进程；
  2. 删除 exe（或解压目录）即可，应用不向系统目录写任何文件；
  3. 如需取消开机自启：在应用内取消勾选，或手工删除注册表 Run 项中的 LearningReminder 值；
  4. 如需清除全部个人数据：删除 %AppData%\LearningReminder 文件夹。

常见问题

为什么任务栏右下角看不到图标？

Windows 11 默认把新应用折叠在托盘区的 ^ 隐藏菜单里。点「隐藏到托盘」时应用会弹气泡说明位置；也可以把图标从隐藏菜单拖到任务栏上永久显示，或在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里开启。

通知弹了但没看到横幅？

检查系统「请勿打扰 / 专注助手」是否开启。开启时横幅会被系统抑制，但通知仍进入通知中心；应用的右下角确认卡片不受影响，会照常出现。

为什么首次运行有 SmartScreen 蓝色警告？

免费软件没有购买 EV 代码签名证书（证书每年需数百至数千元），未签名的新程序首次运行会触发 SmartScreen 提示。点「更多信息 → 仍要运行」即可，也可以核对下载页提供的 SHA256 校验值。

应用会上传我的学习数据吗？

不会。应用不包含账号体系，不联网收集任何信息；唯一的网络行为是你主动点「立即学习」时由系统浏览器打开你自己填写的网址。

修改电脑时间或跨天会怎样？

调度器每秒检查一次日期，检测到跨天后会自动为新的一天重新排期；里程碑勾选状态始终保留，定时询问的当天完成标记会在新的一天重置。

如何知道有新版本？会强制更新吗？

启动后约 8 秒应用会向 GitHub 查询最新发行版（可在「设置 → 关于」中关闭自动检查，也可手动点「检查更新」）。发现新版本时主界面顶部会出现提示条，点「前往下载」跳转发布页。应用不会静默下载或替换任何文件，更新与否完全由你决定。

设置了数据加密，换电脑后打不开怎么办？

加密使用 Windows DPAPI，与当前账户绑定，换账户或换机后无法解密。迁移前请先在「设置 → 数据与隐私」点「导出数据」，把明文 JSON 带到新机器导入；如果已经换机，可尝试把 %AppData%\LearningReminder\backups 下的备份文件带回原账户解密，因此不建议在加密状态下删除旧账户的数据目录。

有问题想直接联系作者？

优先到 GitHub Issues 提交（便于检索与追踪）；也可以到 Support us 页面扫码加作者微信，开发进展、使用问题都欢迎直接聊。

占用内存大吗？

纯托盘驻留（未打开主窗口）时私有内存约 20MB、工作集约 80MB；打开主窗口后约 110–130MB。它不内嵌浏览器内核，适合长期后台运行。
